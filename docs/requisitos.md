# Cliente

## Requisitos Funcionais

+ RF01 - O cliente pode visualizar os produtos na tela inicial sem autenticação (Essencial);

+ RF02 - O cliente pode realizar pesquisas de produtos sem autenticação (Essencial);

+ RF03 - O cliente pode filtrar os produtos por categoria (Essencial);

+ RF04 - O cliente pode filtrar os produtos por tamanho (Essencial);

+ RF05 - O cliente pode filtrar os produtos por cor (Essencial);

+ RF06 - O cliente pode filtrar os produtos por faixas de preços pré-definidas (Essencial);

+ RF07 - O cliente pode filtrar os produtos por características, estação, estilo, caimento e elasticidade (Desejável);

+ RF08 - O cliente pode visualizar os detalhes do produto (nome, preço, fotos, descrição, cores e tamanhos disponíveis) (Essencial);

+ RF09 - O cliente pode selecionar a cor e o tamanho do produto antes de adicioná-lo ao carrinho (Essencial);

+ RF10 - O cliente pode adicionar o produto ao carrinho sem autenticação (Essencial);

+ RF11 - O cliente pode adicionar o produto à lista de desejos com autenticação (Desejável);

+ RF12 - O cliente pode visualizar os itens do carrinho com nome, preço, quantidade e valor total (Essencial);

+ RF13 - O cliente pode alterar a quantidade de um item no carrinho (Essencial);

+ RF14 - O cliente pode alterar o tamanho e a cor de um item no carrinho (Desejável);

+ RF15 - O cliente pode remover um item do carrinho (Essencial);
